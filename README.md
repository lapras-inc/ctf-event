# イベント用 — CTF 問題

このリポジトリは、LAPRAS が開催したセキュリティイベントで出題した CTF 問題一式です。
イベントでは「本物のハッカーに攻撃手法をやさしく解説してもらった」をテーマに、
Web アプリに潜む脆弱性とその攻略手法を題材にしました。

イベントはこちら
https://lapras.com/events/61

各問題は独立した小さな Web アプリとして実装されており、Docker だけで起動できます。
手元で立ち上げて、実際に触りながら挑戦してください。

## フィードバック・お問い合わせ

本リポジトリでは Issue 機能等をオフにしています。フィードバック・お問い合わせは [LAPRAS](https://lapras.com) のチャットサポート、または [ユーザーコミュニティ](https://github.com/lapras-inc/lapras-user-community/discussions) までお願いいたします。

## 注意事項

- **挑戦はローカル環境のみで実施してください。** 公開サーバー等に対する診断・攻撃行為は行わないでください。
- 各問題には `LAPRAS{...}` 形式のフラグが設定されています。フラグは `.env.example` / `compose.yaml` に既定値として含まれており、ローカルで起動すればそのまま検証できます。

## 起動方法（Docker で一発起動）

**必要なもの**: Docker（Docker Desktop / OrbStack / Colima など）

問題ごとにフォルダへ移動して起動します。

```bash
cd 01                      # 挑戦したい問題のフォルダへ
docker compose up --build  # 起動（初回はビルドあり）
```

起動したら、問題ごとのポートにアクセスします。

| # | URL |
|---|-----|
| 01 | http://localhost:8001 |
| 02 | http://localhost:8002 |
| 03 | http://localhost:8003 |
| 04 | http://localhost:8004 |

停止は `Ctrl+C`、後片付けは `docker compose down` です。

フラグや公開ポートを変更したい場合は、各フォルダで `.env.example` を `.env` にコピーして編集してください。

```bash
cp .env.example .env
```
